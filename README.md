# ShopSim Developer Training — Frontend Labs

A structured 9-module lab series covering **React** and **Angular** side by side.  
Each module has a concept explanation, a guided starter project, and a full solution.

---

## How to use this repo

1. **Read the Teams doc** for the module before opening any code
2. **Clone this repo** and work inside the `starter/` folder for each module
3. **Do not look at `solution/`** until you've attempted the lab yourself
4. **Open a PR** with your completed lab on your own branch: `feat/your-name/module-01`

```bash
git clone https://github.com/your-org/shopsim-training
cd shopsim-training
```

## Quick start

### React
```bash
cd react/01-getting-started/starter
npm install
npm run dev
```

### Angular
```bash
cd angular/01-getting-started/starter
npm install
ng serve
```

## Rules during training

- ⛔ No AI tools during labs (first two weeks)
- ✅ Use the cheatsheets in `shared/cheatsheets/`

## Stack

| Layer | React | Angular |
|-------|-------|---------|
| Language | TypeScript | TypeScript |
| Version | React 18 + Vite | Angular 17 (standalone) |
| Styling | Plain CSS (Tailwind from Week 2) | Plain CSS (Tailwind from Week 2) |
| Routing | React Router v6 | Angular Router |
| HTTP | Axios | HttpClient |
| State | useState, useContext, useReducer | Signals, Injectable services |
